# Raccourcis de retouche photo — prompts pour ChatGPT

**Langue : français.** Ce guide propose des mots-clés faciles à copier dans une demande de retouche ou de génération d'image.

> **Important :** les expressions ci-dessous sont des **raccourcis de rédaction (prompts)**. Ce ne sont **pas des commandes officielles de ChatGPT**, ni des scripts exécutables. Pour de meilleurs résultats, joignez une image et décrivez le changement attendu. La disponibilité et la fidélité des transformations dépendent de l'outil utilisé.

## Raccourcis

| Raccourci | Ce qu'il faut demander |
|---|---|
| `/studio` | Placer la personne dans un studio photo professionnel, éclairage soigné. |
| `/background` | Remplacer l'arrière-plan par le décor indiqué dans la demande. |
| `/removebg` | Supprimer l'arrière-plan et demander un fond transparent, si disponible. |
| `/hd` | Améliorer autant que possible la netteté et la qualité de la photo. |
| `/4k` | Demander une sortie haute résolution (4K si l'outil le permet). |
| `/restore` | Restaurer une ancienne photo (défauts, rayures, contraste). |
| `/colorize` | Coloriser une photographie en noir et blanc. |
| `/portrait` | Créer un rendu de portrait photographique. |
| `/beauty` | Faire une retouche discrète de la peau, sans changer les traits. |
| `/light` | Corriger l'éclairage et l'exposition. |
| `/sharp` | Renforcer modérément la netteté. |
| `/cinematic` | Appliquer un style de lumière et de couleurs cinématographique. |
| `/luxury` | Utiliser un décor et une ambiance haut de gamme. |
| `/wedding` | Mettre en scène la photo dans un décor de mariage. |
| `/nature` | Placer le sujet dans un paysage naturel. |
| `/office` | Mettre le sujet dans un bureau professionnel. |
| `/passport` | Préparer un portrait sur fond uni de type photo d'identité ; vérifier séparément les exigences officielles. |
| `/anime` | Transformer l'image dans un style d'animation japonaise. |
| `/cartoon` | Transformer la photo en illustration de dessin animé. |
| `/chibi` | Dessiner le sujet avec des proportions chibi. |
| `/vintage` | Donner un rendu photographique ancien. |
| `/bw` | Convertir la photo en noir et blanc. |
| `/gold` | Ajouter un décor ou des accents dorés. |
| `/christmas` | Placer le sujet dans une ambiance de Noël. |
| `/birthday` | Créer un décor de fête d'anniversaire. |
| `/a4` | Demander une composition prévue pour une impression A4 ; vérifier la résolution. |
| `/keepface` | Préciser : « Conserve l'identité visuelle et les traits du visage, sans les modifier ». L'IA ne garantit pas une conservation parfaite. |

## Exemples à copier

**Portrait professionnel**

```text
/studio /light /keepface
Utilise ma photo. Remplace uniquement le décor par un studio photo professionnel avec un éclairage doux. Conserve les visages, les expressions et les vêtements d'origine.
```

**Portrait élégant**

```text
/studio /luxury /gold /keepface
Transforme l'arrière-plan en studio élégant aux accents dorés, sans modifier les personnes.
```

**Photo pour impression**

```text
/restore /hd /a4 /keepface
Restaure cette photo, améliore la lisibilité des détails et prépare une composition verticale A4 adaptée à l'impression. Ne change pas les traits des personnes.
```

**Suppression du fond**

```text
/removebg /keepface
Supprime seulement l'arrière-plan, en conservant le sujet intact. Fournis un fond transparent si c'est possible.
```

## Conseils

- Joindre la **photo originale** lors d'une demande de modification.
- Préciser ce qui **doit rester inchangé** (visages, tenues, posture, couleurs).
- Pour `/background`, décrire explicitement le nouveau décor.
- Pour `/passport`, les images produites par IA ne remplacent pas nécessairement une photo d'identité réglementaire.
- Pour `/4k` et `/a4`, contrôler les dimensions et la qualité réelle du fichier final avant de l'imprimer.

Ces raccourcis sont des conventions personnelles pour écrire plus rapidement des consignes de retouche photo.
