## Drei ausgewählte Udacity-Projekte

### 1. Analyse eines A/B-Tests im E-Commerce

🔗 [Projekt auf meiner Website ansehen](https://www.franckeale.de/project_3.html)

**Fragestellung:** Sollte eine bestehende Webseite beibehalten oder angesichts der beobachteten Conversions durch eine neue Version ersetzt werden?

Das Notebook umfasst die Untersuchung der Daten, die Prüfung der Zuordnung von Testgruppen und Seitenvarianten, Wahrscheinlichkeitsanalysen, statistische Tests und einen Abschnitt zur Regression.

**Werkzeuge:** Python, pandas, NumPy, Matplotlib, statistische Methoden.

**Praxisbezug:** Eine Entscheidung im E-Commerce anhand von Daten untersuchen und zwischen einem beobachteten Unterschied und statistischer Evidenz unterscheiden. Das Projekt verbindet meine Erfahrung im Onlinehandel mit meinem Lernen in der Datenanalyse.

### 2. Wrangle and Analyze Data — Datenaufbereitung

🔗 [Projekt auf meiner Website ansehen](https://www.franckeale.de/project_4.html)

Sammlung, Bewertung und Aufbereitung von Daten aus Twitter-Archiven mit unterschiedlichen Quellen und Formaten, darunter CSV und TSV.

Das Notebook enthält Prüfungen der Datenstruktur, Datentypen und fehlenden Werte sowie Schritte zur Aufbereitung und Analyse.

**Werkzeuge:** Python, pandas, NumPy, requests, Matplotlib, Seaborn.

**Praxisbezug:** Die Qualität der Daten verstehen, bevor Kennzahlen erstellt werden. Dieses Vorgehen bildet eine wichtige Grundlage für Reporting und Business Intelligence.

### 3. Data Visualization — Untersuchung von Automobildaten

🔗 [Projekt auf meiner Website ansehen](https://www.franckeale.de/project_5.html)

Untersuchung eines Automobildatensatzes in einem Übungsszenario zu Fahrzeugmerkmalen, die mit Preisen zusammenhängen könnten.

Die Arbeit verbindet Datenaufbereitung, den Umgang mit fehlenden Werten, die Umwandlung von Variablen und Visualisierungen zur Untersuchung von Zusammenhängen.

**Werkzeuge:** Python, pandas, NumPy, Matplotlib, Seaborn.

**Praxisbezug:** Daten verständlich darstellen und Beobachtungen mithilfe von Grafiken vermitteln. Das Projekt zeigt meine praktische Arbeit mit Datenvisualisierung in Python.

**Outils :** Python, pandas, NumPy, Matplotlib, méthodes statistiques.

**Intérêt métier :** examiner une décision e-commerce à partir de données et distinguer une différence observée d'une preuve statistique. Ce projet fait le lien entre mon expérience du commerce en ligne et mon apprentissage de l'analyse.

**Outils :** Python, pandas, NumPy, requests, Matplotlib, Seaborn.

**Intérêt métier :** comprendre la qualité des données avant de construire des indicateurs. Cette démarche constitue une base utile pour le reporting et la Business Intelligence.

### 3. Data Visualization — exploration de données automobiles

🔗 [Voir le projet sur mon site](https://www.franckeale.de/project_5.html)

**Outils :** Python, pandas, NumPy, Matplotlib, Seaborn.

**Intérêt métier :** rendre un jeu de données plus lisible et communiquer les observations par des graphiques. Ce projet illustre ma pratique de la visualisation en Python.
